# Token Efficiency Guide

This guide provides tool-specific configuration recommendations to reduce token usage, speed up interactions, and lower costs — all set-and-forget, no ongoing behavior changes needed.

Generated by [quiver](https://github.com/quiver/quiver).

---

## All Tools

### Prune unused MCP tools and servers

Every enabled MCP server's tool schemas load on **every single request**, whether you use them or not. A standard toolset can add 10–15 KB of pure overhead per request. Some setups measured 55K–134K tokens of tool-definition overhead before any work starts.

**Claude Code:**

Edit `.claude/settings.json`:
```json
{
  "deniedMcpServers": ["server-name-you-dont-need"],
  "enabledMcpjsonServers": ["only-the-server-you-need"]
}
```

**OpenCode:**

Edit `opencode.json`:
```json
{
  "mcp": {
    "your-server": {
      "disabled": true
    }
  }
}
```

**GitHub Copilot (VS Code):**

Open the Tools picker (🛠️ icon in Chat view) and deselect MCP servers and individual tools you don't actively use.

For agentic workflows in YAML, narrow toolsets:
```yaml
# Before: loads ~22 GitHub tools
tools:
  github:
    toolsets: [default]

# After: only what's needed
tools:
  github:
    toolsets: [issues]
```

If you have >128 tools, enable virtual tools to auto-manage:
```jsonc
// .vscode/settings.json
{
  "github.copilot.chat.virtualTools.threshold": 20
}
```

**Savings:** Up to 85% reduction in tool-schema overhead.

### Move deterministic work out of the LLM loop

An MCP tool call is a full LLM reasoning step — the agent must decide to call the tool, formulate arguments, and receive output. Running `gh pr diff` via CLI is a deterministic HTTP request with zero LLM involvement.

**All tools:** Use CLI commands as pre-steps before the agent starts:
```bash
gh pr diff $PR_NUMBER > /tmp/pr-diff.txt
gh pr view $PR_NUMBER --json title,body,labels > /tmp/pr-meta.json
```

Then instruct the agent to read these files instead of making MCP calls.

**Savings:** Eliminates entire LLM turns. The cheapest LLM call is the one you don't make.

### Use lighter models for routine work

Not every task needs a frontier model. Simple tasks (formatting, adding tests, fixing lint) can use lighter models at a fraction of the cost.

**Claude Code:**

Use `model: haiku` in subagent definitions for routine tasks. Or switch interactively.

**OpenCode:**

Edit `opencode.json`:
```json
{
  "model": "anthropic/claude-sonnet-4-20250514",
  "small_model": "anthropic/claude-haiku-4-20250514",
  "agent": {
    "plan": {
      "model": "anthropic/claude-haiku-4-20250514"
    }
  }
}
```

**GitHub Copilot (VS Code):**

```jsonc
// .vscode/settings.json
{
  "chat.planAgent.defaultModel": "GPT-4o-mini",
  "inlineChat.defaultModel": "GPT-4o-mini"
}
```

**Savings:** 2–4× per interaction when using lighter models for routine work.

## Claude Code

### Use subagents for high-volume operations

Delegate operations that produce large output (test runs, doc searches, log processing) to subagents. The verbose output stays in the subagent's context; only the summary returns to your main conversation.

```markdown
Use the code-improver agent to suggest improvements in this project
```

### Keep CLAUDE.md lean

- Under 200 lines per file
- Use `@path/to/file` imports for large reference files instead of inlining
- Use `.claude/rules/*.md` with `paths` frontmatter for path-scoped rules
- Only include facts the AI can't infer from code

## OpenCode

### Use skills for on-demand procedures

Skills only load content when invoked, saving tokens on every request. Move long procedures out of `AGENTS.md` into `.opencode/skills/`:

```
.opencode/skills/deploy/SKILL.md
.opencode/skills/review/SKILL.md
```

### Configure compaction

Edit `opencode.json`:
```json
{
  "compaction": {
    "enabled": true
  }
}
```

Compaction avoids the compounding cost of stale conversation history — the #1 driver of token waste in multi-turn sessions.

## GitHub Copilot

### Enable terminal output compression

Every time an agent runs a command, the full terminal output gets sent back as context. One `npm install` can dump 5K+ tokens.

```jsonc
// .vscode/settings.json
{
  "chat.tools.compressOutput.enabled": true
}
```

**Savings:** Collapses unchanged diff hunks, drops lockfile diffs, strips install progress. Thousands of tokens per turn.

---

### Set agent request limits

Unbounded agent sessions can spiral — one misconfigured rule caused a 64-turn fallback loop.

```jsonc
// .vscode/settings.json
{
  "chat.agent.maxRequests": 20,
  "github.copilot.chat.summarizeAgentConversationHistory.enabled": true
}
```

**Savings:** Prevents catastrophic runaway sessions. Auto-compaction keeps context lean.

---

### Disable unused features

Several Copilot features consume tokens silently:

```jsonc
// .vscode/settings.json
{
  "search.searchView.semanticSearchBehavior": "manual",
  "github.copilot.editor.enableCodeActions": false,
  "github.copilot.renameSuggestions.triggerAutomatically": false,
  "github.copilot.chat.newWorkspaceCreation.enabled": false,
  "github.copilot.chat.agent.thinkingTool": false,
  "github.copilot.chat.editor.temporalContext.enabled": false,
  "github.copilot.chat.edits.suggestRelatedFilesFromGitHistory": false
}
```

**Savings:** Each disabled feature eliminates a category of hidden token consumption.

---

### Disable Copilot for unused languages

Copilot is enabled for all languages by default. Every language generates inline suggestion requests even if you never accept them.

```jsonc
// .vscode/settings.json
{
  "github.copilot.enable": {
    "*": false,
    "typescript": true,
    "typescriptreact": true,
    "json": true,
    "python": true
  }
}
```

### Use prompt files for common workflows

Instead of typing (and slightly varying) the same long prompt every time, save it as a `.prompt.md` file.

Create `.github/prompts/fix-lint-errors.prompt.md`:
```markdown
Fix all lint errors in the currently open files. Rules:
- Do not suppress errors with eslint-disable
- Prefer fixing the underlying issue
- Run \`npm run lint\` after fixes to verify
- If a rule seems wrong, note it but still fix the error
```

Enable prompt files:
```jsonc
// .vscode/settings.json
{
  "chat.promptFiles": true
}
```

---

### Disable unused agent config files

If you don't use certain agent frameworks, their config files still get loaded as context:

```jsonc
// .vscode/settings.json
{
  "chat.useClaudeMdFile": false,
  "chat.useNestedAgentsMdFiles": false,
  "chat.instructionsFilesLocations": {
    ".github/instructions": true,
    "~/.claude/rules": false
  }
}
```

## The 3 Most Important Takeaways

1. **Prune tools/MCP servers.** Idle tool schemas charge you on every request. This is a constant tax you can eliminate once.
2. **Enable output compression + keep instructions concise.** These two settings reduce per-turn overhead with zero quality loss.
3. **Move deterministic work out of the LLM loop.** Pre-fetch data, use CLI commands instead of MCP calls. The cheapest LLM call is the one you never make.
